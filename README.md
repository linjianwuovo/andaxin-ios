# 安大信

给本校学生自己写的校园应用：课表、消息、公告、运动、查寝、报修这些原本散在四五个官方入口里的东西，放在一处。

纯客户端。数据直连校方与第三方厂商的接口，没有我们自己的服务器。本机存的就是让这一屏能自己开起来的那几样：登录状态、外观设置、宿舍位置、你自己换的头像、录播看到哪儿、校园卡那把复用会话、首页数字的上一次快照，以及地图瓦片和待上传照片的缓存。没有上传到任何我们自己服务器这条路 —— 我们没有服务器。

## 这不是官方产品

作者是一个在校学生，跟学校没有任何隶属关系，也不代表安徽信息工程学院、安小信或任何第三方厂商。这里用的都是官方 App 本来就在调的那些接口，登录用的是你自己的账号，屏幕上出现的都是你自己账号权限内的东西。

凭据只在你自己手机上：口令用系统 Keystore 里一把不可导出的密钥加密后存本机，不进日志、不进崩溃上报、也不进这个仓。成绩、课表、班内名单这类属于别人的信息只在本机显示，不做导出。学校那边改了流程或者关掉某个入口，对应那一屏就会取不到数，屏幕上会写清是哪一条 —— 这是这类客户端的常态，不是哪里坏了。

## 这个仓的来历

从零写。不继承轻小信（Relianttt/lightxin）及其任何派生仓的一行源码，约束和自查办法见 [docs/CLEAN_ROOM.md](docs/CLEAN_ROOM.md)。

界面上"每一步出自我这"是硬要求：任何一块协议字段，落进代码时旁边要写清证据来自哪次抓包。取不到证的不写，宁可那一屏少显示一行。

## 怎么编

```bash
export JAVA_HOME=/d/app/jdk-21
./gradlew :app:assembleStableDebug      # 开发包：不混淆，装机看效果用这个
./gradlew :app:assembleStableRelease    # 正式包：R8 + 资源压缩 + 你的签名
```

`release` 要签名：在仓根放一个 `keystore.properties`（已经在 .gitignore 里），四个键 `storeFile / storePassword / keyAlias / keyPassword`。没有它 release 出来是未签名包，别当正式包发。密钥库和口令永远不进仓。

## 结构

```
app/AppGraph.kt      手写依赖图，全应用唯一 new 业务对象的地方
core/                平台适配：定位、瓦片地图、坐标换算、存储、网络、实况通知
data/brief/          列表 / 详情 / 表单三种契约
data/local/          没登录时给界面兜底的那份占位：每一屏都能点、能看、能量帧率
data/                各块的 Contract 接口
state/ feature/      ViewModel 与界面
shell/               底栏五格、玻璃栏、公共小块
docs/architecture/   现状模型与目标分层
docs/接入清单.md      每块要哪些字段、还缺哪次抓包
```

依赖选型是性能优先的：没有 Hilt（手写 AppGraph）、没有 Retrofit+Gson（OkHttp + 无反射解析）、13 个 DataStore 合成一份、地图是自己写的 Compose 瓦片层、图标自己画。release 开 R8。

## 现在能干什么

一句话：登录之后每一屏读的都是校方或第三方厂商接口回来的真数据。没登录时才走本机那份占位，
而且屏幕上会写明"未登录，看的是占位数据"——不许悄悄拿假数据当真结果给你看。
AI 课堂那一屏例外：它只问真接口，没登录就直接说拿不到。

底栏五格之外，接上的是这些：

- 课表：全周网格（校方排课那一份），顶上「第一周…第N周」一横行、自动滚到本周，今天那一列有底色；行高按屏幕算，作息表十节照官方抄。
- 首页：问候语带名字、下一节与今日课程、未读数、校历与节假日、服务清单与 banner（点进去是应用内自带的 WebView，带着会话），下半屏「待办事务」四格各挂一个数，点哪格进哪一栏。
- 消息 / 公告：分类列表、未读角标、公告详情是真二级页（正文带图），标已读要连按两次。
- 待办事务：列表、审批链、表单原文回显；同意 / 驳回 / 撤回 / 删除四个写口加批量标已阅。
- 请假：发起那张表按校方的表单形状渲染（嵌套的列、日期区间、自动算时长的公式字段都在），提交走学校那个 `submitForm`；销假先读超假信息再提交。
- 成绩 / 素质学分 / 劳动工时 / 离返校登记 / 班级群与花名册：列表加详情，五模块那屏按学校的分档来。
- AI 课堂：换到第三方课堂平台的会话是后台做的，不用你点"连接"；周次切换、章节与本节内容、课件逐页预览、录播用内置播放器（机位可切，看到哪儿本机自己记）、六位签到码直接摆在第一屏、扫码签到交给带会话的 WebView。公开课那一族另有列表与详情、章节、测验。
- 查寝签到：本月概览六个数、一张签到月历、当天任务两栏（查寝与主题签到），点月历上的日子筛那一天，过去那些日子走的是校方「历史查寝」那一发；月历上那颗点按这天签没签上色。详情接学校那条任务详情（要不要拍照、签到范围、要求那几行、签到时间），签到是拿当前定位（转成它要的那套坐标）提交，要拍照的那场当场拍、照片走校方那个上传口。
- 报修：列表、详情、流程轨迹，详情里校方存着的附图（报修人传的与维修过程中传的）一并显示；新建那张表的三级类型、三段地址、期望时间都按官方形状来；照片最多十张（选图、缩略图、删图都在本机，按下提交之后才往学校传，传不上去就不发这张单）；提交、取消、确认并评价三颗键接上了。
- 校园卡：三跳换到开普那把会话，余额、卡状态、有效期先上屏，流水分"今天"和"近 30 天"两刀。
- 运动：真 GPS 采集（前台服务 + 通知栏那条进度，国产 ROM 上不生效的我们自己补），交上去的形状按官方那一份、坐标转它要的那套；运动记录与明细两屏，地图是自己写的瓦片层，跑完画轨迹用。
- 登录与本机：口令用系统 Keystore 里那把不可导出的密钥加密存本机，记住的话进登录页就填回那一格；票过期能自己续，被别处顶号会写明原因。
- 设置与关于：深浅色、底栏玻璃材质、字号档、桌面那枚启动图标（七枚可选，换的是系统里那条入口）、宿舍位置（签到范围要用）、上课提醒和它的提前量、还有关于页里安大信自己的检测更新（读这个仓的 Releases 订阅，进屏不自动查，点「查一次」才发那一发）。

没接的也写清楚，别当缺陷报：校园卡挂失与充值（校方那三个写口是加密的，算法没抠出来，界面上只写去哪儿办）、体育那屏的「申请维护」提交（参数名一个都没见过）、课堂投票与互动看板。报修那张表的传图口已经接上形状，但学校收不收我们这一发还没人真按过 —— 第一次按的时候如果它报错，那是实证，不是坏了。

所有写操作都停在最后一步由你按：报修提交 / 取消 / 确认并评价、请假提交、销假、同意 / 驳回 / 撤回 / 删除、批量标已阅、消息标已读 —— 这些都要连按两次才发，发送期间禁用，不自动重试。跑步是另一套：「结束」要连按两次，跑完停在结束页，那一趟只在本机，只有你按下写着「提交到学校」的那颗才交出去。查寝签到按一次就发（那是你每天要点的东西，它同时有采集时间窗和定位门槛挡着）。没接上报文的那一侧直接回明确失败，不假装成功。

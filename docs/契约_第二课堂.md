## 2. 身份怎么带（①，出自 `index-f99bbd94.js` 里那个 axios 壳）

```
accessToken: n("access_token")     // 从 H5 自己的存储里取
userCode:    e.userCode || ""
```

- 两个键都进**请求头**，驼峰写法 —— 和报修那一族（`repair.aiit.edu.cn`）同一套习惯，和门户 fdygl 那套（JSON 体 + 头）也像。
- 抓包里同时看到 `cookie`（118 次）和 `x-requested-with`（229 次）；**哪个是必需的没做减法**，别照抄成"必需"。
- 我们这边 `Session` 里本来就有 `accessToken` + `userCode`，接的时候直接复用，不需要新登录。
- H5 那个第三参数 `{showMask:!1}` 是它自己的加载遮罩开关，跟报文无关，不发。

## 3. 响应信封（②，10-25 真报文，把上一节那句 grep 出来的话改回来）

**`{flag, msg, data}`** —— 实样是 `…"flag":true,"msg":"查询成功"}`。上一版这里写的 `{code,msg,data}` 是从文件里 grep 到 `code` 出现 66 次得出的，**打脸了：判成没成看 `flag`，别写死 `code==0/200`**。列表型接口的数组在 `data.records`（②），学分总览在 `data.modules`（②）。

`credit` / `totalCredit` 服务端给的是**字符串**（实样 `"0.05"`），不是数 —— 别自己 `toDouble` 再四舍五入。

## 4½ 参数名（10-25 傍晚从 `dektjs/` 那 36 个分块里逐个调用点抠出来的，①）

GET 走 `params`（查询串），POST 走请求体。`showMask` / `showErrorToast` / `responseType` 是 H5 自己的界面开关，不发。

| 路径 | 参数 |
|---|---|
| `/app/project/list` | `projectName` `categoryId` `moduleId` `rankId` —— **注意它把界面上的"模块"发成 `categoryId`、"类别"发成 `moduleId`，两个键在 H5 里就是交叉赋值的**（`categoryId:a.moduleId, moduleId:a.categoryId`），照抄别自己"纠正" |
| `/app/quality/modules` | 无 |
| `/app/quality/categories` | `categoryId`（传的是选中的**模块** id，同上那对交叉键） |

| `/app/quality/qtypes` | `rankId` |

| `/app/credit/details` | 无（返回按模块 id 分键，`details[moduleId]` 是那一模块的明细） |

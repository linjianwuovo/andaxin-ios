## 一点三之五、公告正文：接口名以前是我编的，今天找到真的了

`CaptureNotices.detail()` 原来那句"正文那条（`news/getNewsDetail.do`）我发过但没验成，先不装成功"
—— **那句接口名压根不是取证来的**，是照旧笔记写的。今天两条硬证据把它推翻：

1. 官方**原生 APK 四个 dex 里 `getNewsDetail` / `newsDetail` 全 0 命中**（外包清点
   `lxtmp/安小信接口全集.md` 第 570 行那张表）。原生只是开一个 WebView 指向
   `zhxy-new-scps/index.do#/headline/news/<id>?returnFromIscToAppFunc=ReturnDefault`
   （`cn/edu/aiit/axx/adapter/NewsAdaptarNew.java:280` 等四处一模一样）。
2. 所以详情是 **H5 那一层**做的。把 `index.do` 引的 114 个 webpack chunk 全扒下来 grep，
   在 chunk 16 里找到方法体：`Object(s.a)("/api/news/getNewsDetail.do", {id: this.$route.params.id})`。

**但那个 `/api` 前缀从 PC 直发是 404**：`/zhxy-new-scps/api/news/…` 全 404，
`in.aiit.edu.cn/api/…` 是 nginx 静态层回 405 —— 照 H5 的字面量抄就是死路。
真能通的是**原生那个不带 `/api` 的前缀**：

```
POST https://in.aiit.edu.cn/zhxy-new-scps/news/getNewsDetail.do     参数只有 id
→ {flag:true, data:{id, bt, content(一整段 HTML), urlList[], publishPerson, publishTime, collect}}
```

列表那一发（`getNewsList.do`）里 `content` 是 **null**，正文只有详情这一发给。
详情条目 21 个键，真用到的就这六个；`fbt/contentExceptPic/title/jumpUrl/picAddress` 实测都是 null。

**渲染**：仓里离线加不了富文本依赖（`~/.gradle` 缓存里没有 Markwon 之类），
所以自己按块级标签切段、清标签与实体，图片走 `urlList` 单独交给界面画 —— 比塞一个 WebView 进去轻得多。
只在**块级边界**断行：校方正文里 `<br>` 用得很随意，按 `<br>` 断会切出一堆一行两行的碎段。
`RemoteImage` 加了 `adaptAspect`：只给 `fillMaxWidth()` 时 `Image` 的高度走的是**原始像素高**，
一张 800×3000 的会议安排长图会原样摆在那儿还被 Crop 裁掉一大截。

装机验过（`4647add`）：《上海闵行职业技术学院来校考察交流》正文分段正常、
"（参观双创展厅）"这种图注保留、四张配图满宽按原比例显示。

## 一点三之十一、10-21 凌晨：会话掉了之后，App 到底能不能自己回来

**现象**：04:0x 装机时登录页上那颗「用这台机器记住的口令登进去」按下去只回一句
"本机记的那份登不进去了"，而「我的」那一格明明写着"已记住，到期或被顶号时能自己重登"。
同一件事两屏互相打脸，而且那句"登不进去"是我在界面上写死的一句猜话，不是代码给的原因。

**取证**（04:4x，`su -c cat` 把 `files/datastore/andaxin.preferences_pb` 拖到 PC 上扫键名）：
`auth.pwBlob` 有值（56 字符 base64），`auth.token` 不在，**`auth.userCode` 这个键根本不存在**。
也就是本机只剩一份没有学号陪着的密文 —— 自动重登两样都要，那一份是解不开的孤儿。
（这里只扫键名和长度，口令、学号、token 一个都没往任何文件里落。）

**成因**：旧代码 `reloginFromVault()` 成功路径是"先清后写" —— `signOut(keepPassword = true)` 紧跟 `save()`，
而旧 `signOut` 里 `auth.userCode` 是**无条件**擦的。这两发之间只要协程被取消一次
（`ensureFresh` 跑在 `LaunchedEffect` 里，App 一进后台就取消），文件里就留下这个半状态。
再回头看 `save()` 覆盖的键：token / refresh / userCode / userName / userType / expiresAt / browsing / generation ——
**正好是 `signOut` 清的那八个**。所以那一发前置清空一个字节都没多清掉，只多留了一个半状态的口子。

**这一批改了五处**：

1. `signOut` 分级：他自己按「退出登录」才清口令；`TokenKeepAlive` 那种"票不作数了"一律 `keepPassword = true`，
   并且**学号跟着口令一起留**（擦学号 = 把口令变成孤儿，就是上面那个案发现场）。
2. 重登成功路径里那次前置 `signOut` 删掉 —— 只剩 `save()` 一把 transaction，写不出半状态。
3. `AuthFeed` 的失败分成两种：学校答了并说不行（`AuthRejected`）才该忘掉口令；
   根本没问到（`AuthUnreachable`：断网、网关给 HTML）**什么都不清**。
   旧代码把两者一视同仁，等于一次网络抖动永久废掉自动重登。
4. `reloginFromVault` 不再只回 Boolean，六种卡点各有各的一句话并直接上屏：
   没接 Keystore / 没留口令 / 学号不在了 / 密钥被系统清了解不开 / 学校不认这份口令 / 这一发没问到学校。
5. `Session.remembered` 的判据从"密文在不在"改成"密文**和学号**都还在" ——
   「我的」那一格和登录页那颗键从此说的是同一句话。账号那一格进来时预填本机留着的学号；
   **口令永不预填、永不落盘、不进日志**。

**还欠一次真机回合**：这台米11 上那份孤儿密文救不回来（学号已经没了），得他输一次口令、
并且勾着「记住密码」。输完之后这条自动重登路才算真验过 —— 在那之前，上面五处只有 ①②⑤ 是读代码定下的，
③ 那两句上屏的话我**没有实样**，别当已验收。

## 一点三之二十八、10-24 凌晨：报修传图那条 blocker 是假的

先前记的是"那座 JSBridge 发 multipart，身份在哪一层没证据"。今晚把 `bxjs/` 那批官方 H5 分块
整个扫了一遍 `uploadForSjd`，**四处调用点全在同一段 `photograph` 组件里，它根本不走 multipart**：

```js
postImg: function () {
  var t = (new Date).getTime(),
      i = {fileImg: this.headerImage},                       // headerImage 是 dataURL
      o = "/api/bxjlSjd/uploadForSjd.do?timestap=" + t;      // 注意是 timestap，学校拼错了
  this.ABILITY.request.post(o, i, !1).then(function (t) {
    e.imgList.push({id: t.data.file.id, src: t.data.file.fileFullName, w: 800, h: 600})
  })
}
```

读出来的六条事实（都出自这段原文，不是我推的）：

1. **它走的还是 `ABILITY.request.post` 那个 wrapper** —— 报修那一族我们**现打验过**只认驼峰 `accessToken` + `userCode`，
   所以这里没有 `FormData`、没有 `multipart/form-data`（这一句"wrapper 就是同一套身份"是我由同族其它口推的，
   上传那一发还没亲手打过）。真正的 multipart 只有劳动工程（`lxgc`）那一族在用
   （`var o = new FormData; o.append("file", t)`，13.js），别把它当报修的样。
2. **图是 base64 数据 URL 直接进字段**：`fileImg = FileReader.readAsDataURL` 的结果，
   前面还过了一段 canvas 压缩（`compress`：`宽×高 > 4e6` 即 400 万像素时按 √ 缩边、白底铺一层再画；
   后面另有一道 `> 1e6` 的判据，只读到判据那半行，缩到哪儿没看着；`rotateImg` 按 EXIF `Orientation` 转正）。
3. **URL 上挂 `?timestap=<毫秒>`**，拼错的那三个字母照抄，别"顺手改成 timestamp"。
4. **响应挂在 `data.file`**：取 `id` 和 `fileFullName`；`id` 进 `imgList`，提交时
   `tpId = imgList.map(n => n.id).join(",")`（20.js / 8.js 两处一致）—— 我们那份 `tpId` 现在写死空串，接上就有了。
5. **两道闸在客户端**：单张原图 `< 5242880`（5MB）否则弹"图片大小必须小于5MB"；条数 `< 10` 否则弹"最多只能上传10张图片"。
6. **提交体比我那份多一个 `loginType`**：8.js 组装顺序是
   `{xqdm, lyId, qyfjh, xxdz, sjh, gzms, xm: userInfo.userName, userCode: userInfo.userCode, tpId, [kssj, jssj], bxlx, loginType}`，

顺带把评价那一屏的原文也捞到了（1.js）：`params = {id: detailList.bxdId, wcqk: qkindex, fwpj: fwindex, yjfk, userCode}`
→ `updateBxdByIdForSjd.do` → `e.flag` 才弹"提交成功！"；`qkchose(0)` 会把 `fwpj` 清成空串 —— 和他旧仓那份判据一模一样。
另外 `pjhbg = userInfo.userType == "1" ? "pjhbg" : "pjhbgt"`，评价环节标志按报修人/维修人分两值，
这一条是拿来看流程列表的，我们暂时用不上，先记着。

**还欠一手实证**：上面全是"官方前端就是这么发的"，不是"我发过、学校答了"。
`uploadForSjd` 成功响应里 `data.file.id` 的形状有了（前端就这么读），但我们自己发一发会不会被
`_userType`/`loginType` 之类再卡一道，得他按一次才知道。所以这一条接进界面以后，

## 三、运动 —— 读侧 10-20 中午接上了，剩下的全在写侧

先记一条踩坑，因为它骗了我两轮：**跑量拉不到不是"不在校内"，是我自己把明文拦掉了。**

`core/net/Http.kt` 里原先写了

## 五、几条别破的规矩

写操作（报修提交、请假提交、待办的同意/驳回/撤回/删除、销假、挂失、付款、跑步上传）一律停在最后一步由人按，失败不自动重试。
这几条的形状与判据**都照他旧项目里已经跑通的那一份**（`lightxin-main` 的 `LeaveRepository.write()` / `RepairRepository.submit/cancel/evaluate`）：
判据只认外层 `flag`，成了重拉一次让学校的状态自己说话 —— 不再拿"成功响应没实样"当卡点复读给他。
挂失、付款这两条本来就没有形状，仍然不许猜。
任何一块只要还在用 `Local*` / `Placeholder*`，界面上那条"占位数据"的说明就不许摘。
取不到证的东西不写进代码，宁可那一屏少显示一行。
证据分三等：① 我读到的代码 ② 我自己发出去的请求 ③ 目标 App 发出被我抓到的报文。
只有 ① 的（比如 fdygl 那两条签到/补签写接口，是从前端代码里读到的），代码里和界面上都要写明"没现打验证过"。
